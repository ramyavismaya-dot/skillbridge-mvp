# SkillBridge AI — MVP Demo

A working prototype of the full SkillBridge AI loop: **assess → predict → train → place**,
covering all three sides of the platform (student, university, employer).

This is a real, runnable Next.js app — not a mockup. It's intentionally built with the
simplest possible stack so it runs anywhere with zero external services, and is meant as a
starting point to demo to pilot universities/employers and to hand to a developer to extend.

## What it does

- **Student** (`/student`): takes an 18-question interest inventory (RIASEC / Holland Codes)
  plus a 6-skill self-rating, and gets back an AI-generated Skills & Career Report — top
  career fits with match scores, plus a personalized training roadmap of skill gaps and
  recommended courses.
- **University** (`/university`): a career-services dashboard showing cohort-level interest
  clusters, average skill levels, and every student's top career fit — the aggregate view a
  real career-services office would want.
- **Employer** (`/employer`): post a role (picking the closest of 14 role templates), and see
  every student in the database ranked by fit score, with matched/gap skills and a short
  AI-written rationale for the top candidates.

All three views share one scoring engine (`lib/riasec.ts`), so a change to a student's
profile immediately changes what employers see — that's the "closed loop" from the business
plan.

## Running it

```bash
npm install
npm run dev
```

Open http://localhost:3000. Data is stored in `data/db.json` (created automatically); delete
it any time to reset the demo.

### Optional: turn on real AI narratives

Out of the box, the report/match blurbs are generated by a deterministic, rule-based template
(no API key needed — the app is fully functional without one). To upgrade those blurbs to
real Claude-generated narratives:

```bash
cp .env.example .env.local
# then edit .env.local and set ANTHROPIC_API_KEY=sk-ant-...
```

## What's real vs. simplified (read before pitching or deploying)

This is scoped as an MVP to validate the core loop fast, not a production system. Specifically:

| Area | Current MVP | Before real users |
|---|---|---|
| Assessment | 18-item RIASEC + skill self-rating, not validated | Have an I/O psychologist review or license a validated instrument |
| Database | Local JSON file (`lib/db.ts`) | Real database (Postgres via Supabase/Neon); JSON file won't work on serverless hosts |
| Auth | None — name/email only, no accounts | Real auth (Clerk/Auth0/NextAuth) before any real student data is collected |
| Course catalog | Static mock list | Real integration with a content partner (Coursera for Business, Udemy Business, or an LMS) |
| Matching | Simple weighted-overlap score | Refine with real outcome data over time, per the business plan's feedback-loop design |
| Hosting | `npm run dev` / `npm run start` on one machine | Any Node host works; just swap `lib/db.ts` for a real DB first |

## Project structure

```
app/
  page.tsx                 landing page
  student/                 assessment form, report, roadmap
  university/               cohort dashboard
  employer/                 job posting + ranked candidates
  actions.ts                server actions (form submissions)
lib/
  riasec.ts                 questions, role dataset, scoring/matching engine
  courses.ts                 mock course catalog + roadmap builder
  ai.ts                      Claude narrative generation with rule-based fallback
  db.ts                      JSON-file persistence
```
